# Установка, запуск и генерация через окно

**Preview 0.1.1-preview:** сервер, переводы и ресурсы встроенного worker проверены программно; новые GPU-генерации в этом обновлении не выполнялись. Нажатия кнопок, диалоги выбора папок и полный путь установки через нативное окно пока не подтверждены; установка на чистой машине не проверялась.

## Для обычного пользователя Windows

1. Распакуйте **весь** архив [FLUX3-Manager-Windows-x64.zip](https://github.com/DevelopmentOpenworld/flux3-pascal-8gb/releases/download/v0.1.1-preview/FLUX3-Manager-Windows-x64.zip) в удобную папку. Дважды нажмите **FLUX3-Manager.exe**. Папка `_internal` должна оставаться рядом: в ней Python, библиотеки окна и данные приложения. CMD, PowerShell и отдельная установка Python для этого пути не нужны.
2. В разделе **«Где хранить скачанные файлы»** выберите папку с примерно 10 ГиБ свободного места. Движок и три модели – около 6,23 ГиБ загрузки; если CUDA нет, добавятся около 411 МиБ загрузки и распакованные библиотеки.
3. Если файлы уже есть, нажмите **«Обзор…»**: папка с `sd-cli.exe` и его DLL, модель FLUX.3, Qwen, VAE, папка CUDA или её `bin`. Используются точные версии из `assets.lock.json`. CUDA 12 определяется автоматически при наличии необходимых DLL. Выбранные файлы используются на месте, без копирования.
4. Если файлов нет, оставьте соответствующие поля пустыми и нажмите **«Скачать недостающее»**. Движок загружается с GitHub, модели – с Hugging Face, CUDA Runtime/cuBLAS – с NVIDIA. Видны текущий файл, объём и проверка SHA256. **«Отменить загрузку»** сохраняет принятую часть. Повторная загрузка продолжает её при поддержке HTTP Range; иначе перезапускает этот файл.
5. Для уже имеющихся файлов нажмите **«Проверить и сохранить»**. Проверяются размеры и SHA256 моделей и закреплённого состава движка. CUDA проверяется на наличие `cudart64_12.dll`, `cublas64_12.dll`, `cublasLt64_12.dll`; это не измерение её производительности. После скачивания проверки выполняются автоматически.
6. Нажмите **«Запустить сервер»** – генератор откроется в браузере. **«Открыть генератор»** возвращает вкладку. **«Остановить сервер»** останавливает сервер и его текущую генерацию. Закрытие окна Manager также останавливает относящийся к нему сервер. Закрытие одной вкладки оставляет сервер работающим.

Настройки сохраняются в `%LOCALAPPDATA%/FLUX3Pascal`, скачанные файлы – в выбранной папке. Установленная CUDA переиспользуется. При её отсутствии скачиваются локальные библиотеки CUDA 12.6.3: системный Toolkit, PATH и драйвер не меняются. Нужен работающий драйвер NVIDIA.

Имеющиеся отличающиеся файлы и неизвестные частичные загрузки не перезаписываются. При несовпадении SHA256 выберите правильный файл или другую папку. После сетевого обрыва повторите скачивание: завершённые файлы проверяются и используются снова.

EXE распространяется отдельным переносимым пакетом, без весов, движка и CUDA. Он не подписан сертификатом издателя; при блокировке запуска решение принимает владелец компьютера. Программа не меняет защитные настройки.

Дополнительные внешние обёртки запуска подключайте в варианте из исходников. Обычный Windows-пакет использует прямой встроенный worker.

## Язык интерфейса и обновление

В правом верхнем углу Manager выберите **Русский / English**. Выбор сохраняется в локальном `manager.json` и действует после следующего запуска. Manager открывает генератор на выбранном языке; в самом генераторе доступны кнопки **Русский / English**. Браузер запоминает свой выбор в локальном хранилище; при его блокировке выбор остаётся в адресе вкладки. Язык интерфейса не переводит промпт, надписи внутри изображения, имена файлов или исходную диагностику внешних компонентов.

Переключение доступно во время проверки, скачивания и генерации. Оно обновляет подписи, подсказки, ошибки и этапы, сохраняя пути, параметры, прогресс и текущий PNG. Само переключение не запускает и не повторяет генерацию, не останавливает сервер.

Для обновления остановите сервер старым Manager, закройте его и распакуйте новый ZIP в отдельную папку. Запустите новый EXE; локальные настройки из `%LOCALAPPDATA%/FLUX3Pascal`, выбранные модели и установленная CUDA используются повторно. Не удаляйте старую папку, пока не убедитесь в запуске новой версии. Существующий сервер не обновляется на месте. Если запущен вариант из исходников, остановите и перезапустите его из обновлённых исходников; затем обновите страницу генератора.

Автоматические проверки этого обновления выполнялись без открытия нативного окна и без новых GPU-генераций. В тестах Manager виджеты и файловые диалоги заменены программными заглушками; настоящие серверы запускаются в отдельных временных настройках и портах. Это проверяет обработчики и сервер, но не размеры/отрисовку окна и поведение системных диалогов. Системные кнопки внутри файловых диалогов используют язык Windows.

## Для запуска из исходников

Путь для разработчиков: `Start-FLUX3.cmd` или `python scripts/app.py`. Само окно Manager: `python desktop/launcher.py`. Испытан Python 3.14.4 x64; для нативного окна нужен рабочий Tk. Внешние Python-пакеты приложению не нужны. Движок и веса можно подготовить по [REPRODUCE.md](REPRODUCE.md), сборка EXE описана в [BUILD_WINDOWS.md](BUILD_WINDOWS.md).

При запуске сервера из исходников укажите в его настройках пути к sd-cli.exe, FLUX.3 Q4_0, Qwen3-VL 4B Q4_K_M, FLUX.2 VAE и bin CUDA Toolkit 12.6. Дополнительный каталог DLL можно оставить пустым. Бюджет VRAM – 6 ГиБ. Браузерная кнопка «Проверить и сохранить пути» проверяет наличие; SHA проверяет `python scripts/verify.py --config config.local.json`. В Manager проверка SHA встроена в кнопку готовности.

Выберите пример или введите описание; задайте размер, seed, шаги и CFG; нажмите «Сгенерировать». Измеренный профиль – 16 шагов и CFG1. Размеры кратны 16, 256–1536 по стороне, площадь не больше 1024². Seed – 0–2147483647, шаги – 1–64, CFG – 1–8; доступные варианты за пределами измеренного профиля не имеют обещанного качества или времени.

## Текущий результат

Приложение показывает одну текущую операцию, без списка прошлых запусков и без API такого списка. Оно не читает внешние пользовательские каталоги и не восстанавливает завершённые задания после перезапуска сервера.

**Сохраните исходный PNG до следующей генерации или выхода.** Промпт и параметры включены в PNG. Рабочие файлы создаются в собственной временной папке приложения; следующая генерация удаляет предыдущие временные файлы, нормальное завершение очищает папку. Выбранные в конфигурации внешние каталоги с пользовательскими файлами не очищаются.

Обновление страницы во время работы показывает ту же текущую операцию. Новый запуск приложения после завершения сервера начинает с пустого результата. «Отменить» завершает собственное дерево процессов; «Завершить приложение» закрывает сервер. Закрытие вкладки само по себе не останавливает текущую генерацию.

## Подключение и этапы

Обычный адрес – `http://127.0.0.1:8440`; локальная случайная сессия сохраняется при перезапуске. Не пересылайте полный адрес со сессией и не публикуйте app-session.json. Другой порт задаётся явно, например `python scripts/app.py --port 8441`; занятый порт не заменяется случайным незаметно для пользователя.

Если связи нет, нажмите «Запустить сервер» или «Открыть генератор» в Manager, затем «Повторить подключение» в браузере. Повторное подключение сохраняет введённые настройки и не повторяет POST генерации автоматически. После потерянного ответа клиент сначала сверяет единственную текущую операцию, что предотвращает повторный запуск изображения. Порт можно явно изменить в окне Manager.

Счётчики загрузки весов вроде `316/316` не являются шагами диффузии. Индикатор различает подготовку моделей, генерацию с заданным числом шагов и преобразование в PNG. Процент – приблизительная стадия, а не точное оставшееся время. На 1024² VAE может автоматически перейти на плитки; предупреждения и задержка входят в работу движка.

## Локальные настройки и проверка

config.local.json, app-state.json и app-session.json исключены из Git и пакета. Конфигурацию можно хранить вне проекта: `python scripts/app.py --config .\local\config.json`. Сервер слушает только 127.0.0.1; API требует сессию и проверяет Host, изменения также проверяют Origin. Облачной службы и удалённого доступа нет.

Автоматические проверки: `python -B -m unittest discover -s tests -v`. Они проверяют скачивание по локальному HTTP, отмену и возобновление, SHA256, отказ от перезаписи, распаковку, отсутствие восстановления прежних запусков, один текущий результат, сохранность внешних файлов, перезапуск, соединение и подпись этапов. GPU-модель в этих тестах не запускается. Свидетельства генератора – [ui-proof/verification.json](../ui-proof/verification.json), графического Manager – [desktop/verification.json](../desktop/verification.json).
