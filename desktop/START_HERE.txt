FLUX.3 Manager · Windows x64

1. Распакуйте всю папку. Откройте FLUX3-Manager.exe.
   Не переносите EXE отдельно от _internal.
2. Выберите папку для скачанных файлов.
3. Укажите имеющиеся файлы кнопками «Обзор…»
   ИЛИ оставьте поля пустыми и нажмите «Скачать недостающее».
4. Нажмите «Проверить и сохранить», затем «Запустить сервер».
5. В браузере выберите пример, параметры и нажмите «Сгенерировать».
6. Сохраните PNG до следующей генерации или остановки.
7. «Остановить сервер» в Manager останавливает приложение.
   Закрытие Manager также останавливает его сервер.

Python уже включён. Имеющаяся CUDA 12 переиспользуется.
Если её нет, кнопка скачивания подготовит локальные библиотеки CUDA.
Драйвер NVIDIA, системная CUDA и системный PATH не меняются.
Для файлов оставьте примерно 10 ГиБ свободного места.

Настройки сохраняются локально в %LOCALAPPDATA%/FLUX3Pascal.
История генераций не ведётся. При перезапуске результат пуст.
Модели, движок и CUDA скачиваются отдельно из закреплённых источников.
Неподписанный EXE может потребовать решения владельца компьютера.

Дополнительные внешние команды запуска подключаются в версии из исходников;
обычный Windows-пакет использует прямой встроенный worker.

Предварительный публичный выпуск 0.1.0-preview. Установка на чистой машине
и визуальная проверка нативного окна не подтверждены.
